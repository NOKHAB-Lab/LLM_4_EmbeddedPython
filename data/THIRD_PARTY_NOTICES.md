# Third-Party Notices

This dataset includes Python code derived from public GitHub repositories, adapted into a prompt–completion format for instruction tuning. All included code was **modified** (reformatted, varied, and in some cases regenerated) from the originals.

This file preserves the copyright and license notices required by the source licenses. **Per the MIT / BSD / Apache terms, the copyright notices below are retained here** even where an individual `completion` no longer carries the original header. If you reuse a completion containing a substantial part of one of these works, you must keep the corresponding notice below (or the original header) — the MIT condition still applies.

Sources with **no license file** are not included in this release (see the final section). If you are an author and want your code included, removed, or relicensed, please open an issue / contact the maintainer.

Each record in the dataset also carries machine-readable provenance under `metadata.provenance` (`source_repo`, `source_url`, `license`, `license_class`, `redistributable`).
